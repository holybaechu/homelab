# Applications

The [homelab package](compose/homelab/README.md) runs Traefik, AdGuard Home,
Cloudflare DDNS, qBittorrent, Copyparty, and MeTube on `docker_apps`.

Edit services and application configuration in `compose/homelab/`. Use the
[operations guide](../docs/operations.md) to deploy changes or roll
back, and the [secrets guide](../secrets/README.md) to prepare credentials.
